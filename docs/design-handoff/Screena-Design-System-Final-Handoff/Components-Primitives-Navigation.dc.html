Button família

Uma família única substitui as 32 assinaturas atuais. Elemento: <button> (ação) — nunca <span onClick>. Tamanhos xs/sm/md/lg (alturas 30/36/44/52, toque md=44). Radius radius-control 8 (ou 0 em contexto editorial).
