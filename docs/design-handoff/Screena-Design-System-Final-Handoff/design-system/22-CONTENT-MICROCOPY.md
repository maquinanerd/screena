# 22 — Content & Microcopy (D3C)

Voz da Cinerie: **editorial, cinéfila, direta e honesta** — em português do Brasil. Sem marketing genérico, sem promessa que o produto não cumpre.

## Princípios
- **Honestidade acima de tudo:** nunca “inscrito!” sem confirmação; nunca disponibilidade/nota inventada; nunca “em breve” sem contrato real.
- **Campo ausente é omitido** — nunca “N/D”, “—” decorativo ou zero como ausência.
- Frases curtas; verbo de ação nos CTAs; sem jargão de SaaS.

## CTAs
| Contexto | Copy |
|---|---|
| Detalhe de título | Ver detalhes · Assistir ao trailer · + Watchlist |
| Trailer | Watch ▶ |
| Editorial | Ver tudo · Ler mais |
| Newsletter | Assinar |

## Estados (microcopy honesta)
| Estado | Copy |
|---|---|
| Empty (watchlist) | “Sua watchlist está vazia” + ação sugerida |
| Empty (rail) | “Nada por aqui ainda” |
| Error | “Não foi possível carregar as recomendações” + “Tentar de novo” |
| Offline | “Você está sem conexão” |
| Cinerie Score insuficiente | “Dados insuficientes” (`< 5 avaliações`) |
| Cinerie Score não calculado | “Ainda não calculado” |
| Streaming região | “Não disponível na sua região” |
| Streaming sem dados | “Ainda não temos informações de onde assistir este título” |
| Newsletter sucesso | “Confira seu e-mail” (confirmação necessária) |
| Episódio futuro | “Estreia prevista para {ano}” |
| Spoiler | “Toque para revelar a sinopse” |

## Rótulos fixos
- Publicidade: **PUBLICIDADE** (sempre).
- Score próprio: **Cinerie Score** (nunca “nota”, nunca misturado a fonte externa).
- Tipos: **Filme** (vermelho, tinta escura) · **Série** (verde, tinta escura).

## Transparência
- Correção: “Correção ({data}): {o que mudou}.”
- IA: declaração explícita (“Sem uso de IA generativa na apuração ou redação” quando aplicável).
- Atribuição de imagem/fonte quando exigida.
